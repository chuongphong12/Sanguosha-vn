## Reproduced compatibility gap

`src/game/hegemony/nullification.ts:145–162` decodes both raw and converted responses using `readCardUse`. Its non-Skill guard throws for a raw SkillCard at line 157, before `runNullification` can invoke `validateResponse` at lines 340–347. Native `verifyNullificationResponse` accepts any successfully parsed card, then `_askForNullification` saves the original and calls `validateInResponse` before Heg classification. Native Miewu explicitly supports Nullification and supplies a concrete SkillCard conversion example.

The external reproduction copies the current Nullification test fixture, makes the race return a normalized Miewu-shaped SkillCard with `userString="nullification"`, and registers a conversion child returning an ordinary Nullification. It calls actual public scheduler dispatch and the actual Nullification operation. Expected conversion/lifecycle completion instead throws `Invalid card use` in readCardUse -> readResponse -> runNullification. The conversion child is not reached. This is a descriptor/dispatch reproduction with a conversion fixture, not execution of the Miewu package.

The reproduction was repeated, including richer user-string metadata and a final control with a distinct raw SkillCard reference/non-trick ancestry versus the converted Nullification reference. Every selected run exited 1 with the same behavioral failure before conversion. Each run selected one reproduction and skipped the 79 existing fixture test declarations. Import failure or missing handler is not the signal. The unchanged full project suite separately passes; this new case exposes a missing compatibility scenario in the planned SkillCard response integration.

Proposed bounded repair, not yet implemented: use the shared execution descriptor reader for raw/converted response shape while preserving private reference validation, original/converted identity, null-conversion retry, original validateAfter and strict unrelated non-Skill onUse entry. Add permanent regression, null/rejected conversion, malformed data, distinct references and pause/reload exactly-once cases. Do not coerce a SkillCard into a basic/trick card or silently enable a package.
