## Executed composition

A trusted normal-turn-step captures the regular actor, enters real TurnStart and phase lifecycle, then uses one Proceeding bridge in place of the standalone Draw rule. RoundStart uses actual ask-general-show/show-general; Judge moves the captured delayed card to table, invokes real card-effect/CardEffected and package-directed real discard movement. Draw uses actual drawing/pile/movement operations once. Play routes actor-only offers through existing card-command admission and Room/card-on-use/CardUsed/Card-use/CardFinished, then real free-chain. Discard uses mandatory rule-discard admission and physical movement, with token cost real when selected. Finish/NotActive use actual history/mark/flag cleanup. No second Room or independent current-phase state is introduced.

The synthetic package supplies a target-fixed Test card with a no-op effect, implied recipient, validation/metadata, general eligibility/change/preshow/filter/notification adapters, max-cards based on HP plus token increase, Jilei=false and normalized yes/no choice. Test fixture authentication treats a supplied actor string as authenticated; it is not network authentication. Presentation is suppressed. Delayed-card behavior is a synthetic package discard, not an implemented native trick identity. These boundaries must remain explicit; this suite does not test Slash/Jink/damage/rescue/winner, competitive bots or all native packages.

## Persistence, routing and recovery evidence

Thirteen cases cover a complete bounded normal turn; complete game/scheduler outcome comparison at budgets1/7/10000 with JSON at every actor-prompt/cooperative-yield boundary; token-spend/discard composition; an extra turn and advancement relative to the regular anchor; face-down skip; three interruption reasons at CardFinished inside real Room use; stale Play answer rejection at Discard and actor-only admission views; inserted Draw and skipped Play. The scheduler comparison normalizes optional yielded absent versus false. Physical IDs remain conserved. The suite uses three seats and a single serialized test driver, not concurrent service writers or the complete2–10-seat acceptance matrix.

At the CardFinished interruption, the played material is already on table and the earlier Judge card is in discard. TurnBroken/StageChange unwind actual Room cleanup, moving the table material to discard; GameFinished (normalized game-over) skips that native catch and retains it on table. Only TurnBroken is followed by recover-normal-turn and the next actor's real turn. No application policy for StageChange/GameFinished is invented. Match-v3 still owns reason classification, root/save validation, sole-writer enforcement, bounded pumping, safe private routing/projection, startup handoff and terminal ownership.

## Evidence limits and next step

The initial incomplete composition failed for missing phase-proceeding after a separate missing-queue fixture correction; neither is reported as an existing engine defect. An assertion initially failed on a mistaken assumption that CardFinished had already discarded the material; actual source orders the final discard afterwards. That expectation was corrected, preserving native GameFinished behavior. A Standards review found the skipped-Play test also passed when Play merely declined; the test now asserts no Play Start/Proceeding. Deliberately omitting skipPhase fails the new assertion, then restoring it passes. This is sensitivity validation of new tests, not a production bug fix.

The new composition is test-only. M1.3.5 must supply actual application ownership and an internally enabled minimal-profile setup-to-terminal scenario including real damage/rescue/winner where applicable. Full content,2–10-seat rooms, durable hosted sessions/recovery/load, competitive bots, media/provenance, UI and production cutover/rollback remain required. Main stays unmerged and PR33 stays draft.
