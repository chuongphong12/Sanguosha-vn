## Room cancellation and hegemonic cache

`card-cancellation` asks current package isCancelable before requiring resources. Noncancelable returns false without tag changes. A cancelable effect captures its original stable reference and current `<key>HegNullificationTargets`; cached recipient returns true without resetting shared tags or asking. Missing cache defaults empty; supplied malformed/null cache rejects. Duplicate/unknown string entries remain native list data.

On a cache miss, eagerly set HegNullificationValid=false, NullifyingTarget/Source/Card and NullifyingTimes=0, then delegate a positive ask. Source can be null. Ask returns boolean independently of the valid bit. Afterward, only current true validity plus current original-reference ND-trick ancestry appends currently living friends of the original recipient to the saved list, in registration order without deduplication. Write using the original reference's current key. Nested asks leave their shared tags intact; the outer saved list can replace a nested cache write. Interrupted asks do not perform fanout or restore eager tags. Friendship must come from private [general authority](generals-and-relations.md), not Standard roles or public projection.

Its normalized result is null or a roster member plus a parsed card/reference; the engine does not replace that race with sequential player prompts. ## Slash preparation and response

`slash-on-use` clears target-fix/assignee flags on currently living seats, transfers no-distance/disable-extra-target flags to current card storage, handles a positive drank mark and delegates repeated-Slash cause to an adapter. That adapter owns Play-phase and shown paoxiao → shown paoxiao_xh → Crossbow precedence. The current flags flow into common onUse; slashDisableExtraTarget suppresses TargetSelected. Wrapped and virtual references retain their own resource storage.

`slash-on-effect` consumes one signed integer from the source's current-key Jink list even if disresponsive then sets the requirement to zero. Emptying removes the tag; otherwise keep the remainder. A nonnull source/nonempty adapted list is required. Missing drank defaults zero; nature is package-resolved. Consumed Jink requirements are not restored after a later error.

Room `slash-effect` always emits SlashEffected at the original recipient, including a dead seat. Only consumption removes original recipient's Global_NonSkillNullify and one current-key Qinggang entry; duplicates are preserved by remove-one semantics. `slash-result` uses the explicit jink argument on its local effect: null emits SlashHit at source only if recipient remains alive; nonnull removes one Qinggang entry and emits SlashMissed even for a dead recipient. Terminal rewrites/consumption do not redirect cleanup. Nullable sources/slash are supported by these Room wrappers.

`jink-effect` returns false for null user/card; otherwise require current Jink ancestry, then check ResponseNegated. A true negation skips the event; otherwise return inverse JinkEffect consumption at user. Parsing, conversion, MethodUse/material lifecycle and actual input stay with askForCard.

Priority-zero SlashEffected consumes nullified effects, emits SlashProceed at source for positive Jink count or delegates null-result otherwise. SlashProceed captures latest effect, requires known nonnull source and checks target alive once before asking. Single request is `slash-jink:<source>`; multiple asks count down `@multi-jink-start:<source>::<N>` then `@multi-jink:<source>::<remaining>`, pattern jink, MethodUse, copied original local context. Missing/ineffective Jink fails immediately; success passes only final Jink to Room. Death mid-chain does not suppress remaining asks; Room still gates a failed hit by current alive.

Pure predicates/descriptors receive copies and stay outside serialized continuations. JSON resume, replay rejection and eager interruption semantics follow the [scheduler](scheduler.md). Physical Jink/Peach test adapters and full pipeline fixtures establish ordering, not the unported generic askForCard or network race. Target distance/legality, weapon/skill overrides, concrete package conversions, live pointer/subcard identity, UI/AI/network and exception unwind remain external gates. Actual damage/rescue are described in [HP flow](damage-and-rescue.md).
