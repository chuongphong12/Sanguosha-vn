## Authority and conclusion

Native authority is **2.3.43-beta2, ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f**, under the active game's `.references/qsanguosha-upstream`. Game baseline is **1fc4ff20bf261c3b7cf85c9d5c6c3a4b90e4cbae**; knowledge lock is c471bbe0e020be55750691365e54a3cf911b715a. The older attached binary distribution is not the source of these counts.

The native tree contains substantially more ordinary Quốc Chiến content than the 60-general base. Static source reconstruction identifies **176 general definitions across 12 ordinary candidate general packages**, plus **179 C++ physical card allocation expressions** across 10 card packages. These are definition/allocation counts, **not a selectable roster, active draw pile, registered runtime catalogue, enabled package list, implementation coverage percentage, or release promise**. Bans, hidden variants, lord conversion, DIY policy, treasure exclusions and dynamic Lua must be resolved before freezing the manifest.

Q29 excludes Joy, Disaster and jile_card. Q30 clarifies that the target is ordinary Quốc Chiến, not Vương Triều Chiến, with no treasure flow: keep LordEXCard disabled and do not introduce its independent four-trick variant. This does not exclude the separate LordEX general package. These are release-profile decisions, not claims that native non-treasure tricks require the treasure. Remaining gaps below are research/validation work.

## Graph-first method and limitations

Queried GitNexus LocalBackend 1.6.12 using exact absolute active-game and native paths, read repository context, searched package/loading/general/registry concepts, then disambiguated constructor/deck/DIY context by UID. Native context was ce4e62b with 871 files, 34,663 symbols and 317 processes; game context was 113b99b, one lock/metadata-only commit behind current game HEAD, with 342 files, 10,263 symbols and 513 processes. No index mutation was run. Native contexts expose limited edges (notably no incoming call for getRandomCards); source confirms Room constructor calls it. Empty edges/processes are not evidence of no dependency.

Followed graph discovery with primary-source reading and a line-preserving balanced-delimiter static extractor over package C++/headers and extension Lua. The extractor strips comments, records constructor arguments/owners/source lines, resolves class inheritance and direct literal names, then manually confirms eight default-argument skill names and eight horse instance names. It does not compile Qt, execute Lua, read a user's persisted settings, enumerate a live native Engine, or prove registration/selection success. Conditional/dynamic skills require follow-up closure.
