# M0 — ArcheryAttack as a bounded MethodResponse caller

Inspected 2026-10-27. Native authority: QSanguosha 2.3.43-beta2 at `ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f`; web source: `3c835ce7a4ebdf89e1754d150a3dc31040977e58`. This investigation explains the caller added to the isolated session prototype, not a complete card-package port. Executed checks belong to [the checkpoint](../reviews/2026-10-27-hegemony-m0-method-response.md); the reusable boundary is [the session contract](../engine/prototype-session.md).

## Native semantics inspected

- [AOE availability and onUse](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/package/standard.cpp#L208-L255): fixed-target admission is distinct from expanding the effect targets. With an empty requested target list, native onUse enumerates other players and applies prohibition checks; an explicitly populated list is retained before delegating shared TrickCard use. The prototype supplies an explicit no-prohibition/no-skill authority and expands other living fixture seats; it does not implement native prohibition skills.
- [ArcheryAttack::onEffect](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/package/standard-tricks.cpp#L140-L159): disresponsive and wrapped-card EffectNoResponse state can suppress the request. Otherwise request Jink with **MethodResponse**, carrying the effect and a living source recipient (or null). Missing response causes one normal damage. This is different from Slash's direct MethodUse Jink and its JinkEffect/SlashMissed envelope.
- [DamageStruct card constructor](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/core/structs.cpp#L132-L160) initializes empty reason, chain/transfer/prevented false and by_user true; its [header declaration](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/core/structs.h#L44-L46) supplies damage 1 and Normal nature by default. The native reason accessor can derive the card object name. The fixture caller preserves these defaults rather than inventing an explicit Archery skill reason.
- [Room response lifecycle](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/server/room.cpp#L1801-L1847): MethodResponse uses its own movement, CardResponded, cleanup and after-hook sequence. Existing normalized [direct request contracts](../engine/direct-card-use.md) retain the distinction from MethodUse.
- [Discard insertion](https://github.com/TamQuocSat-LangKhach/QSanguosha-QuocChien/blob/ce4e62b31c4d1a65de79188be11ccdd4f0ac6f9f/src/server/room.cpp#L5277): movement prepends to the discard pile. Jink 1 resolves before outer ArcheryAttack 2 finishes, producing top-first discard `[2, 1]`. An initial test expectation `[1, 2]` was corrected against this source; the movement kernel was unchanged.

## Web composition and authority limits

The new [archery caller](https://github.com/chuongphong12/Sanguosha-vn/blob/3c835ce7a4ebdf89e1754d150a3dc31040977e58/server/prototypes/hegemony-m0/archery.ts) runs actual shared card-on-use and ask-card-response operations with serializable continuation data. [Battle composition](https://github.com/chuongphong12/Sanguosha-vn/blob/3c835ce7a4ebdf89e1754d150a3dc31040977e58/server/prototypes/hegemony-m0/battle.ts) binds existing physical Jink acquisition/validation to the distinct MethodResponse operation. No separate client opcode or client-supplied arbitrary card descriptor is added. The session still commits state, continuation and receipt before publication.

The owner receives generated legal choices and a method discriminator; the public observer receives only the CardResponded event name, not its private payload. The existing actor-only bot sees the same legal offers. Public Socket.IO, automatic-decision, storage and browser assertions are pinned through the checkpoint.

[Engine metadata/admission](https://github.com/chuongphong12/Sanguosha-vn/blob/3c835ce7a4ebdf89e1754d150a3dc31040977e58/server/prototypes/hegemony-m0/engine.ts) changes physical card 2 from synthetic Slash to ArcheryAttack. Per-card offers allow it after Slash history is spent; using it does not consume the Slash allowance. The fixed two-seat/4-HP/eight-card/seat-0-Play fixture remains. Registry/save identity is now `PROTOTYPE-ce4e62b-response-v4`: old clock-v3 saves are rejected. Use a fresh scratch file or new SQL `M0_STORE_NAME`; no migration or older-code rollback is certified.

Nullification is explicitly disabled by the fixture's false cancellation authority. This slice does not establish full ArcheryAttack/AOE package parity, all multi-target/prohibition/disresponsive/tag interactions, skills/equipment/conversions, lethal rescue, full turns, native runtime equivalence, competitive bots, hosted durability or release readiness. The existing library contracts remain broader than the fixture consumer; their code is unchanged here.
