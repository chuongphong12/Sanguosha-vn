# Canonical knowledge with a versioned subtree

Developers and AI agents need the matching documentation after ordinary game clone and branch switching. Keep canonical Hegemony knowledge in a fresh public repository and import reviewed, exact commits as a squashed subtree in the game; this deliberately retains documentation bytes in the game in exchange for setup-free checkout. A separate lock records the imported commit and tree, while the source baseline records the inspected game revision without requiring circular self-references.
