# Complete the agreed manifest before the first small-group release

The first small-group release must include the entire agreed ordinary Quốc Chiến manifest, competitive bots and complete art/audio. A smaller executable subset remains useful for internal engineering proofs but does not satisfy that release gate; the user explicitly selected full scope over an earlier partial-roster launch, with quality gates rather than a fixed date.

Consequently, manifest inventory, asset gaps and feasibility are resolved before a detailed completion forecast. Free-tier failure does not authorize silently shrinking content or bot quality. [Roadmap decisions](../plans/hegemony-release.md) record the selected scope; [release spec](https://github.com/chuongphong12/Sanguosha-vn/issues/25) defines the observable result.
