# Trusted bounded battle turn owner

M1.3.5a adds [createMatchTurn](https://github.com/chuongphong12/Sanguosha-vn/blob/46025ce4653373ecbe3f796bd96093a56c0ee358/src/game/hegemony/match-turn.ts) at 46025ce4653373ecbe3f796bd96093a56c0ee358, compared with 9235157e2c9ae64d73fe9cc679f8ee9f6cbec605. This is the first internal owner slice under the [accepted B design](../specs/hegemony-turn-unwind.md), not the completed match-v3 application. Existing match-v2/startup/M0/production and shared scheduler are unchanged. See the [checkpoint](../reviews/2026-11-05-hegemony-m135a-turn-owner.md).

## Interface and persisted authority

createMatchTurn accepts a versioned registry with unwind=true, a positive finite integer stepBudget, unique operation names and the normal-turn-step/recover-normal-turn roots. Its trusted validate/advance interface consumes a TurnMatch containing the same Room, scheduler and a turn cursor. The cursor is normal/recovery with waiting, finished, or fault with StageChange/missing-result reason and captured interruption. Room.turnOrder still owns normal/extra anchor; Room.playerPhases still owns phase. No parallel gameplay authority is introduced.

A call advances at most one bounded scheduler quantum, starts one trusted operation root, or consumes one completed root/unwind. It never consumes a completed root and starts the next in the same call. Control roots such as advance-to-next-seat require their own call. This is stricter than one completed TurnStart per pump. Actor prompts return false without mutation; finished/fault states also return false. Actor decisions still use the existing admissions or known nested prompt route outside this owner. A false result from requested dispatch/continue/unwind is an explicit error, not an idle response.

Root completion is retained in waiting state until a later call validates/consumes the expected operation name, null input and permitted result. Consumption clears the old completion fields, preserving nextId, Room/RNG and normal/extra cursor. An idle Room with an actual terminal string finishes before another root. The caller must supply a fully idle handoff and consume startup completions before entering this owner; no startup handoff is implemented by this file.

## Native unwind and explicit boundaries

A pending interruption is passed with its exact saved identity to the actual opt-in scheduler. Cleanup remains inside the real operations. The owner waits for stack departure and the distinct unwind completion before classifying. TurnBroken schedules a separate recovery root; its completion returns to idle normal ownership without automatically starting another turn. A new TurnBroken inside recovery abandons that root, unwinds and schedules recovery again from current Room facts. A new reason during a cleanup supersedes the old reason; an abandoned Room catch is not re-entered.

StageChange becomes a retained fault rather than a normal next turn. GameFinished (normalized game-over) finishes only with a Room result; a bare interruption without a result becomes game-over-without-result fault. GameFinished skips the Room cleanup used for TurnBroken/StageChange, preserving table material. A cooperative budget-one checkpoint can have an empty frame stack and a remaining unwind marker before publishing completion; validation explicitly permits that real scheduler boundary.

validate checks the owner cursor/table/seat-order/result, frame identities against monotonic nextId, expected root, paused prompt/interruption boundary, permitted root completion and stopped-state consistency. It is not a complete untrusted JSON/Room/nested-handler continuation validator. The scheduler can still reject deeper conditions; requested trusted execution then throws explicitly before silently stalling. Full aggregate restore validation belongs to the next match-v3 slice.

## Executed evidence and exclusions

[27 new owner cases](https://github.com/chuongphong12/Sanguosha-vn/blob/46025ce4653373ecbe3f796bd96093a56c0ee358/tests/hegemony/match-turn.test.ts) exercise actual normal turns, bounded JSON work, paused prompts, three interruption classes, real Room cleanup, repeated recovery, fresh cleanup interruption and a suspended synthetic presentation child. They reject selected invalid profiles/cursors/root boundaries and corrupted-inner scheduler continuations without advancing candidates. Some invalid-condition tests deliberately edit saved JSON; they are not normally created gameplay histories. The terminal case invokes real game-over from a synthetic package listener, not a real winner reached through combat.

The [shared three-seat package fixture](https://github.com/chuongphong12/Sanguosha-vn/blob/46025ce4653373ecbe3f796bd96093a56c0ee358/tests/hegemony/composed-turn-support.ts) was extracted from the preceding [13 composition tests](https://github.com/chuongphong12/Sanguosha-vn/blob/46025ce4653373ecbe3f796bd96093a56c0ee358/tests/hegemony/composed-turn.test.ts); their test bodies and moved fixture bodies are unchanged after export/line-ending normalization.
