## One current phase and native queue state

PhaseGame.playerPhases is the only current phase authority. Native phases normalize to round-start/start/judge/draw/play/discard/finish/not-active, with none as the in-transition sentinel. This preserves the existing web not-active spelling rather than introducing native wire enum integers or round_start/not_active aliases.

phaseQueues stores the separate native phases list, phase-state list (phase/finished) and current index. These are queue/skip state, not a second current phase. Direct change removes only the phases head, so phases and states may legitimately differ. A new play rebuilds both lists but retains the old index until its living-actor loop sets the new index; a dead-entry branch can retain an index past the new list. Safe queries then see no remaining matching phase. An out-of-range insert is rejected rather than adopting undefined native container behavior.

## Operations and package helpers

- createPhaseOperations registers play-phases, change-phase and execute-phase on the existing scheduler. Rules supply a phase-property notice operation or explicit null; free-chain must be composed as a real named operation. Unknown required children fail instead of becoming successful no-ops.
- play-phases accepts target/phases. Empty input uses the native eight-phase order; a nonempty sequence gains NotActive only if absent. Before each living iteration set none, emit Changing, run free-chain, then adopt the rewritten destination into both queue lists and current phase and send its notice. If Changing was consumed or the live finished bit is set, emit Skipping. Consumed Skipping restores execution. An unconsumed skip checks the queued destination (not mutable current phase) and continues directly to the next iteration, bypassing the post-execute break. NotActive still emits Skipping when eligible and always executes Start if that queued destination remains NotActive.
- change-phase accepts target/from/to. It sets none and emits Changing, but retains the supplied fixed destination. A consumed change to a destination other than NotActive restores the supplied from and returns true, without notice, queue removal or execution. Otherwise set the fixed destination, send its notice, remove only phases.head, execute the phase and return false. No separate Changing free-chain belongs to direct change.
- execute-phase emits only Start when its entry phase is NotActive. Otherwise emit Start, run free-chain, emit Proceeding only if Start was not consumed, then free-chain. If alive at the later gate, emit End and free-chain. A later death does not undo Proceeding; phase/life changes are read at their native boundaries, not continuously revalidated by analogy.
- skipPhase marks the first matching remaining state from the live index, or all states for null. Its boolean says whether native skip would permit a log: already-finished first match returns false, an absent phase still returns true. Log delivery stays a presentation adapter. isPhaseSkipped reads the first remaining match; insertPhase adds both queue entries immediately after the live index. None of these changes current phase.

Dead actors encountered by play dispatch actual direct change to NotActive and stop. After an executed phase, current NotActive terminates play. During skip's continue path that post-execute test is intentionally bypassed. Phase source/target admission and queue shapes validate before root allocation; late required-child errors retain earlier eager phase/queue effects.

## Suspension, interruption and integration boundary

Private operation continuations retain stages, loop index, captured phase-change data and consumption. Phase notices and events use the same scheduler children/prompts/IDs. JSON restore and trusted cooperative continuation do not replay accepted stages. Prompt choices remain actor-private through getTriggerPrompt; wrong actor/unoffered/duplicate answers are rejected by the existing scheduler. This is not a new public match view or an aggregate save validator.

These native phase methods add no catch hooks: TurnBroken/StageChange/GameFinished initially freeze eager state; trusted scheduler unwind departs phase frames without inventing NotActive/End or rolling back state. The real outer recovery owner belongs to M1.3.4. Do not start the next actor by clearing the interruption.
